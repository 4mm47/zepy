## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within **ZEPY**:
1. Do **NOT** open a public issue.
2. Please use GitHub's [Private Vulnerability Reporting](https://github.com/4mm47/zepy/security/advisories/new) to report the issue confidentially.
3. We will review the submission promptly and coordinate a patch and responsible disclosure.
